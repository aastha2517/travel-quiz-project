What I Learned from the Travel Quiz Website :
While developing this Travel Quiz Website, I gained practical experience in frontend development and JavaScript functionality.

**1. Website Structure & UI Development**
- Created a complete landing page with Header, Hero Section, Dynamic Category Section, How It Works Section, and Footer.
- Developed separate Quiz Category Detail, Question, and Score sections.
- Designed a clean, user-friendly and responsive interface.

**2. JavaScript Functionality**
- Dynamically displayed quiz categories.
- Implemented a timer for to finish Quiz.
- Added functionality to check correct and incorrect answers.
- Implemented question skipping functionality.
- Tracked the time taken to answer questions.
- Calculated quiz scores based on user answers.
- Created a leaderboard with different legends/ranks.

**3. Logic Building & Problem Solving**
- Practiced conditional statements and JavaScript functions.
- Managed quiz data and user interactions.
- Worked with dynamic content and DOM manipulation.
- Improved debugging and problem-solving skills.

**4. Key Takeaway**

This project helped me understand how to combine HTML, CSS, Bootstrap, and JavaScript to build an interactive, dynamic, and responsive website. It also improved my logical thinking and confidence in developing real-world frontend projects.
